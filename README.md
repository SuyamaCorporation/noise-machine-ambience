# Noise Machine Ambience

Ambient sound mixer with 5 programmatically generated channels: White Noise, Brown Noise, Rain, Café Murmur, and Forest — all produced via Web Audio API with no external files.
Each channel has an independent volume slider and mute toggle; a master volume slider and auto-stop timer round out the controls.
Up to 5 named preset mixes can be saved and reloaded from localStorage (`nma_presets`).
